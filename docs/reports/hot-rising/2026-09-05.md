#### 中文分析

把语音生成、识别和长音频制作集中到自己的电脑上，是 VoiceStudio 最鲜明的体验：无需账户、API key、订阅或用量计费，本地流程中的声音、项目、设置与输出默认留在机器内。桌面端提供 Voice Cloning、Voice Design、Video Dubbing、听写、故事与有声书制作；首次克隆时进入 Voice Cloning，加入一段干净的人声样本，三秒即可尝试，通常 5 至 15 秒效果更好，再输入文本、选择语言并生成。视频配音会串起转写、翻译、说话人保留、语音合成和视频导出，有声书流程则支持多角色脚本、EPUB/PDF 导入、章节渲染与 .m4b 导出。它内置 16 TTS 与 11 ASR 引擎，并用 Model Catalogue 管理模型的安装、删除、选择及路由；646 种 TTS 语言是目录规模，实际覆盖与质量仍取决于所选引擎。计算可走 CUDA、Apple Silicon MPS/MLX、Linux ROCm 或 CPU，也能把任务交给远程 worker。除桌面应用外，还提供本地 REST/SSE/WebSocket API、OpenAI compatible audio API 和 MCP Server。首次启动会建立受管理的 Python 环境并下载默认模型，后续直接复用；若发生故障，可在设置中运行 Run self check，或执行 uv run python backend/main.py diagnose deep 获取深入诊断。

传统 CRM 等人填写表单，Comp AI CRM 则把 CRM 视为智能体持续保存调查笔记的地方：智能体在独立部署中按自己的 schedule 和 work queue 运转，会选择下一条任务、安排复查并消耗研究预算，即使关闭浏览器也不会停止。它坚持不猜测人物信息，工具只报告观察到的证据，ledger 决定证据价格；强证据写入记录，弱证据留作人工裁决的建议。运行结构同样围绕可审计性展开：工具是文件、skill 是 Markdown、schedule 也是文件，dispatch.ts 只租用到期任务并为每行启动会话，claimDue 借助 FOR UPDATE SKIP LOCKED 避免多个调度器领取同一工作。sandbox 提供 bash、grep、glob 和 /workspace，却采用 deny all egress，也不接收 DATABASE URL，使 shell 只能处理文本而无法直接外传客户邮件或访问数据库。联系人、公司和交易的 Agent tab 会展示执行步骤、放弃线索的理由以及需要人工回答的问题；即使没有外部 API key，read crm history 仍能从内部邮件线程、会议和签名块中提取证据。
