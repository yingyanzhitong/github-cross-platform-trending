#### 中文分析

Laya 处理的不是开放式文本生成，而是对任意文本、邮件、工单或 JSON 状态一次性回答 choice、score 和 yes/no 一类有类型的问题；README 在 T4 上测得单个问题的基准耗时为 33 ms，批处理为每题 7.2 ms。由于采用 非自回归 的单次前向传播，输出无需再从生成文本中解析，README 也以“没有文本生成”解释其可控性。内置 Router 会检测文字与语言，在三个 checkpoint 之间为每次请求选择模型：英语、100+ languages 的 multilingual，以及专门服务 typed decisions 工作流的版本。命令行可直接运行 laya "My payment failed twice" --preset triage 套用现成问题集；Python 侧安装可用 uv add laya，并按需要选择 serve、mcp、langchain、onnx 或 structured 等扩展。multilingual 最长可读取 8,192 tokens，但默认上限是 1,024，长文需显式传入 max_len=8192，且 README 明确提醒超过约 4,000 tokens 后准确率波动，应在自己的数据上验证。若零样本 checkpoint 不够准确，还可用领域决策数据执行 RLCD 微调、温度校准、评估与导出。
