#### 中文分析

Ram Altman 把一次关于个人电脑闲置 DRAM 的争论写成了可运行的 bash 笑话：脚本读取 Linux 的 /proc/meminfo，只要可用内存超过默认 10% 阈值，就每天至多发送一封邮件，向收件人汇报这台机器“错过分配”的 RAM。数字并非编造，它记录总量、已用量与可用量，把每次采样写入 CSV，并轮换 8 个主题、10 段正文和 6 种落款。内存计算本身相当认真，优先采用内核给出的 MemAvailable，将可回收 page cache 计入可用内存，却不把 tmpfs 和 shared memory 当成可直接归还的空间；遇到 3.14 以前没有该字段的内核，才以空闲内存和可回收缓存估算。运行需要 Linux、bash，以及 sendmail、msmtp 或 mail，加入 crontab 后可每五分钟采样，发送失败则在下一轮重试。README 反复提醒真正发送邮件并不是玩法重点：--dry-run 能看到完整笑料，仓库不附带任何人的邮箱地址，也不应伪造发件人、批量部署到服务器群或骚扰他人。内存核算是认真的，通信内容则是戏仿；执行 ./test-ram-altman.sh 还可用模拟内存和假 sendmail 跑完 14 项测试，不会触碰真实收件箱。
