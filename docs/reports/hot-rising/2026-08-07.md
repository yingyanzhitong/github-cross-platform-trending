### 1. [TencentCloud/TencentDB-Agent-Memory](https://github.com/TencentCloud/TencentDB-Agent-Memory)

[↖️ 返回表格中的 #1](#project-row-1)

#### 中文分析

当一个 Agent 已经读过文档、理解过项目背景或完成过复杂任务，TencentDB Agent Memory 会把这些经验沉淀下来，避免后续会话和团队成员重新摸索。它将内容整理为四类可管理资产：Chat Memory 保存偏好、事实、决策和交互历史，并按 L0 Conversation、L1 Atom、L2 Scenario、L3 Persona 逐层提炼；Skill 不只是提示词片段，还带有版本、资源文件、触发边界、执行步骤与验证规则；Wiki 把产品文档、设计规范和运维手册转成带链接图谱的结构化页面；CodeGraph 则索引代码符号、文件、调用关系和影响路径，帮助 Agent 在修改前检查调用方、被调用方及潜在波及范围。Memory Hub 是人类控制这些资产的操作面板，可创建团队与 Agent，审核、共享和装配记忆，并管理所有权、版本、状态、可见性及绑定关系。权限支持 private、team、restricted 和针对 Agent 的精确装配，个人生成的记忆默认保持私有。初次使用可克隆仓库，进入 deploy/global-images，复制并填写 .env 后运行 ./start-all.sh，一次启动 memory-core、memory-hub 与 proxy，再打开 http://localhost:8125。已有代码库、文档和历史会话也能导入，分别生成 CodeGraph、Wiki、Skills 与 Chat Memory，让不同职责的 Agent 只加载真正需要的团队经验。

### 2. [esengine/DeepSeek-Reasonix](https://github.com/esengine/DeepSeek-Reasonix)

[↖️ 返回表格中的 #2](#project-row-2)

#### 中文分析
