#### 中文分析

与按网页权威性排序的传统搜索不同，/last30days 把近 30 天里真实用户的注意力和资金选择当作信号：Reddit upvotes、X likes、YouTube transcripts、TikTok engagement、Hacker News 讨论热度以及 Polymarket odds 会被并行检索、交叉评分，再由 AI agent judge 汇总成一份短报告。它特别适合追踪快速变化的话题、公司或人物，因为结果能够把散落在帖子、评论、长视频转录、GitHub 提交和预测市场中的近期动态拼接起来，而不是停留在旧简介。基础运行接近 Zero config，Reddit、HN、Polymarket 和 GitHub 可立即使用；首次运行的设置向导可继续解锁 X、YouTube、TikTok、arXiv、Techmeme 等来源，部分平台允许带入自己的密钥或浏览器会话。不同信号各有分工：Reddit 提供带赞数的真实意见，YouTube 从长篇内容中提取关键语句，GitHub 展示 PR 速度、热门仓库与发布记录，Yahoo Finance 则在研究上市公司时对照同期股价和 S&P 500。README 同时说明当前采用 v4 pipeline，而最新命令与设置行为应以运行时 skill spec 为准。
