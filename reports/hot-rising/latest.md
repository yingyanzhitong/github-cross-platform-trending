#### 中文分析

把 AI 智能体做成通讯录里的联系人，是 OpenMausBot 最鲜明的产品形态：侧栏中的每个机器人都是真正运行在本机的 Claude 或 Codex 进程，各自拥有独立的人设、模型、对话记忆、计算机和已连接应用。用户像聊天一样分派工作，可在 Computer panel 观看桌面实时画面，必要时通过 Open desktop 接管；Shell 命令、文件修改和问题则以 Allow / Deny 等内联审批卡出现。底层由监听 127.0.0.1 的本地服务统一管理进程，记录、密钥和事件保存在 ~/.openmausbot，并复用用户已有的 CLI 登录与订阅。机器人既可操作云端 Linux 桌面或隔离的 Local VM，也可在明确授权且安全边界受支持的平台上控制宿主机；通过 Composio Sessions 还能以 OAuth 接入 Gmail、Slack、GitHub、Notion、Linear 等应用。Channels 用来隔离工作、个人或不同项目的记录、共享指令、工作目录和机器人名单，模型还可在对话中途切换，因而整套体验更接近一支可观察、可审批、可分别配置的智能体团队，而非单一助手窗口。
