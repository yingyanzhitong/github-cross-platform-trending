### 2. [Comfy-Org/ComfyUI](https://github.com/Comfy-Org/ComfyUI)

[↖️ 返回表格中的 #2](#project-row-2)

#### 中文分析

可视化 node graph 把图像、视频、音频、3D 与文本生成流程拆成可连接、可复用的节点，让创作者能够逐项控制模型、参数和输出；复杂图还能整理为 reusable subgraphs、保存成 JSON，或通过 workflow templates 直接载入，生成媒体中也可恢复完整工作流与种子。执行层采用 asynchronous queueing，并结合 partial graph re-execution、显存与内存管理、模型卸载及量化模型支持，修改局部节点后不必无差别重跑整张图。模型既可按完整 checkpoint 加载，也能分别组合扩散模型、VAE、文本编码器、LoRA、ControlNet、adapter 和放大器，并提供局部重绘、扩图、蒙版合成、分割、深度估计、插帧等内置工具。入门可在 Windows 与 macOS 使用桌面应用，Windows 也有便携包；手动安装覆盖 NVIDIA、AMD、Intel、Apple Silicon 和 Ascend 等设备，模型文件通常放入 ComfyUI\models\ 对应子目录，额外模型位置可由 extramodelpaths.yaml 配置。工作流可借助 App Mode 暴露为简洁界面，也能通过 local API 接入生产应用；本地核心默认不会自行下载内容，若要关闭可选的付费 API 节点并强制内置功能离线，可使用 --disable-api-nodes。
